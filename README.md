
# Algorand Certificate Verification System

## Project Overview
A blockchain-based certificate verification system built using the Algorand blockchain.

## Objective
The project aims to provide a secure and transparent way to verify the authenticity of digital certificates using Algorand.

## Planned Technologies
- Algorand Blockchain
- Python
- Algorand SDK
- HTML/CSS/JavaScript

## Project Status
Initial project repository created. Development will be continued throughout the course.
